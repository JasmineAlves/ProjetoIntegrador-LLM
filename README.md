# ProjetoIntegrador-LLM
Projeto Integrador de construção de um Large Language Model (LLM) da matéria de Inteligência Artificial e Sistemas Inteligentes da UNOESC

# Documentação
Esta pasta reúne a documentação do projeto. Seu objetivo é registrar informações 
importantes para facilitar o entendimento, a manutenção e a evolução do sistema.

# Experimentos
Esta pasta reúne testes realizados durante o desenvolvimento, como comparação de algoritmos, 
ajustes de parâmetros e protótipos.
Os arquivos desta pasta não representam necessariamente a versão final do projeto.

# Glossários técnicos
Este documento reúne os principais termos técnicos utilizados no projeto, com suas respectivas definições.
O objetivo é padronizar a terminologia e facilitar a compreensão do projeto.

# Notebooks
Esta pasta contém os notebooks utilizados durante o desenvolvimento do projeto.
São destinados à exploração de dados, realização de análises, testes e prototipagem 
permitindo documentar o processo de desenvolvimento 
de forma interativa.

# Relatórios
Esta pasta armazena os relatórios produzidos ao longo do desenvolvimento do projeto.
Os relatórios registram as atividades realizadas em cada Sprint, os objetivos alcançados, 
as dificuldades encontradas, os resultados obtidos e os próximos passos do projeto.

# Resultados
Esta pasta armazena os resultados obtidos ao final de cada Sprint , como gráficos, 
tabelas, métricas e outros artefatos produzidos caso necessário.

# src
Esta pasta irá conter o código principal do projeto.
Exemplos de arquivos:
- main.py
- preprocessamento.py
- modelo.py
